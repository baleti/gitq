# Golden corpus for the Haskell -> Rust port.
#
# Format: one case per line, "<mode> <query>".
#   q  run plain and --sexp; compare stdout + exit code
#   c  run --complete and --complete-annotated; compare stdout
#   e  error case: compare stderr + exit code (the fail-loud catalogue)
#
# A leading ~ on the mode marks an EXPECTED divergence: the port fixes this
# gap deliberately, so a diff here is the intended change, not a port bug.
# Everything without ~ must match the 0.7.0 binary byte for byte.
